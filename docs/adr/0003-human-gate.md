# ADR-0003 — Human gate for sensitive evidence

**Décision :** les changements scientifiques sensibles ne sont pas promus automatiquement au statut confirmé par un LLM.

**Pourquoi :** les erreurs de classification sont plus coûteuses que quelques minutes de revue.

**Conséquence :** l’automatisation prépare le dossier ; l’humain valide les cas significatifs jusqu’à preuve suffisante d’une automatisation plus sûre.
