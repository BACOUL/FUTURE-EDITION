# Gates de lancement

Future Edition n’est public comme média de référence que lorsque :

## Données
- 10 questions définies.
- Au moins 5 événements vérifiés par question.
- 100 % des affirmations importantes reliées à au moins une source.
- IDs et relations validés.

## Produit
- Home, Aujourd’hui, Questions, Question, Avancée, Preuves, Radar, Chronologie, Méthodologie.
- Mobile et desktop testés.
- Aucun état scientifique fictif ou placeholder présenté comme réel.

## Pipeline
- ingestion locale ;
- déduplication ;
- classification ;
- proposition de source primaire ;
- création de fiche candidate ;
- validation humaine.

## Qualité
- validation de données PASS ;
- build PASS ;
- liens critiques PASS ;
- accessibilité de base PASS ;
- aucun secret dans le repo ;
- historique de correction disponible.

## Lancement éditorial
Le lancement n’est pas conditionné au nombre d’articles mais à la qualité de l’observatoire.
