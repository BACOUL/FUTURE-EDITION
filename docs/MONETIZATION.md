# Monétisation

## Principe

Le média grand public doit pouvoir rester gratuit. La valeur économique provient progressivement de l’audience, de la marque et surtout du Future Graph.

## Phase 0 — Validation
Objectif : usage et crédibilité. Aucun paywall.

## Phase 1 — Média
- publicité limitée et non intrusive ;
- sponsoring explicitement identifié ;
- newsletter sponsorisée.

## Phase 2 — Pro
Fonctions professionnelles payantes possibles :
- alertes sectorielles ;
- veille personnalisée ;
- exports ;
- dossiers de synthèse ;
- historiques/comparaisons avancés.

## Phase 3 — Data/API
- API par volume ou abonnement ;
- licences de données ;
- flux spécialisés ;
- intégrations entreprises/médias/recherche.

## Phase 4 — IA comme client
- accès machine-readable ;
- licences pour assistants ;
- accords de contenu/données ;
- mécanismes de rémunération des crawlers lorsque techniquement et contractuellement pertinents.

## Garde-fous
- aucun sponsor ne peut acheter un statut de preuve ;
- aucune publicité ne modifie un jalon ;
- les conflits d’intérêts sont déclarés ;
- contenu sponsorisé visuellement distinct ;
- corrections indépendantes du commercial.

## Métriques économiques
Ne pas optimiser le RPM au détriment de la confiance. Suivre :
- revenu / 1 000 lecteurs récurrents ;
- revenu B2B par actif de donnée ;
- part des revenus non publicitaires ;
- coût d’exploitation par événement vérifié.
