# Spécification des identifiants

Les IDs sont stables, non traduits et indépendants des slugs.

- Question : Q-001
- Milestone : Q-001-M1
- Technology : TECH-0001
- Event : EV-2026-000001
- Claim : CLAIM-000001
- Evidence : EVID-000001
- Source : SRC-000001
- Provenance : PROV-000001
- Organization : ORG-000001
- Person : PERSON-000001

## Règles
- jamais réutiliser un ID supprimé ;
- un rename ne change pas l’ID ;
- une traduction ne crée pas un nouvel objet scientifique ;
- les fusions conservent un alias/tombstone vers l’objet canonique ;
- les IDs séquentiels sont attribués par l’outil de création, pas à la main à terme.
