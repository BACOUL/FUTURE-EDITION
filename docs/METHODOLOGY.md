# Méthodologie de preuve — socle

## Hiérarchie des sources

### A — Primaire forte
Publication originale, registre d’essai, autorité réglementaire, base officielle, rapport technique officiel, données expérimentales publiées.

### B — Secondaire spécialisée
Revue scientifique, média spécialisé sérieux, analyse d’expert identifiable.

### C — Communication
Communiqué d’entreprise, université, conférence ou présentation.

### D — Signal
Réseau social, vidéo virale, forum, capture, agrégateur, contenu IA.

Une source D peut déclencher une enquête mais ne valide jamais seule une affirmation.

## Pipeline de décision

Signal → source primaire → authenticité → statut → claims → evidence → limites → contradiction → réplication → état précédent → changement proposé → validation.

## Niveaux de preuve

### Médecine
M0 hypothèse · M1 in vitro · M2 animal · M3 premiers humains · M4 essai contrôlé · M5 essai avancé/réplication · M6 autorisation · M7 usage clinique réel.

### Technologie
T0 concept · T1 simulation · T2 prototype · T3 démonstration contrôlée · T4 pilote réel · T5 déploiement limité · T6 échelle significative · T7 usage courant.

### Science fondamentale
S0 hypothèse · S1 modèle/prédiction · S2 observation initiale · S3 validation expérimentale · S4 réplication indépendante · S5 consensus robuste/usage scientifique.

## Confiance

- confirmed
- solid_preliminary
- needs_confirmation
- contested
- misleading
- unverifiable
- retracted_invalidated

## Règle d’or

Le niveau de preuve décrit **ce qui a été démontré**, pas l’importance médiatique du résultat.
