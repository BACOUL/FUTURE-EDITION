# Critères de succès, échec et pivot

## Ce qui compte
Future Edition doit créer une habitude de consultation et une confiance supérieure à une réponse générique.

## Mesures post-lancement
- visiteurs récurrents ;
- taux de retour sur 30 jours ;
- usage des pages Question ;
- clics "Voir les preuves" ;
- profondeur de consultation des chronologies ;
- Reality Checks consultés ;
- abonnements/alertes ;
- citations externes ;
- trafic provenant d’assistants IA ;
- temps humain par événement publié.

## Signaux d’échec
À évaluer sur une fenêtre suffisante et non sur quelques jours :
- très faible retour malgré acquisition significative ;
- pages Question moins utiles que les articles ponctuels ;
- aucune valeur perçue du niveau de preuve ;
- coût humain de validation incompatible avec l’exploitation solo ;
- aucune amélioration mesurable par rapport à une IA généraliste.

## Pivot
Un pivot peut changer le format (Reality Check, observatoire, API, vertical santé...) mais ne doit pas abandonner sans preuve les actifs Future Graph / provenance.
