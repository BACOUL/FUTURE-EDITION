# Gouvernance éditoriale

## Rôles
- **Directeur de publication** : responsable légal à déterminer avant lancement.
- **Editorial gate** : valide les changements scientifiques sensibles.
- **Commercial** : n’a aucun droit de modification sur les conclusions.

## Désaccords scientifiques
Si deux sources sérieuses divergent :
1. conserver les deux ;
2. identifier précisément le point de divergence ;
3. attribuer le statut `contested` si nécessaire ;
4. ne pas produire un faux consensus ;
5. mettre à jour lors de nouvelles preuves.

## Corrections
Chaque fiche importante conserve :
- date de première publication ;
- date de dernière vérification ;
- changements de statut ;
- raisons de correction ;
- liens vers sources nouvelles ou invalidées.

## Droit de réponse
Prévoir une adresse et un workflow dédiés. Toute demande reçue est horodatée, identifiée et traitée selon le droit applicable.

## Conflits d’intérêts
Les relations financières pertinentes d’une source, d’un auteur ou d’un sponsor sont conservées comme métadonnées lorsqu’elles sont connues et matériellement pertinentes.
