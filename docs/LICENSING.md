# Licensing strategy

## Situation initiale
Le repository est public mais aucun droit supplémentaire sur les contenus éditoriaux ou données n'est implicitement accordé au-delà de ce que prévoit la loi. Une licence explicite sera choisie avant ouverture à des réutilisations tierces importantes.

## Séparation à prévoir
- code ;
- schémas ;
- données factuelles ;
- textes éditoriaux ;
- images/illustrations ;
- contenus tiers cités.

Ces catégories peuvent recevoir des licences différentes.

## Objectif futur
Permettre une réutilisation machine raisonnable de certaines données sans abandonner la capacité de monétiser l'API, les enrichissements et les usages commerciaux à grande échelle.

## Gate
Aucune promesse de licence ouverte globale avant revue des conséquences juridiques et économiques.
