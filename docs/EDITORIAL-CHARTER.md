# Charte éditoriale

## Ton
- précis ;
- lisible ;
- non sensationnaliste ;
- explicite sur l'incertitude ;
- optimiste seulement quand la preuve le justifie.

## Titres
Un titre peut être engageant, mais ne doit pas dépasser la preuve.

Interdit :
- "X guérit le cancer" si l'étude est animale ;
- "révolution" comme substitut à une analyse ;
- "100 % certain" hors cas réellement démontrables.

## Santé
Future Edition informe ; il ne donne pas de diagnostic ni de conduite thérapeutique individuelle. Les articles médicaux doivent préciser population, stade de preuve et limites pertinentes.

## Prévisions
Distinguer strictement :
- fait observé ;
- étape officiellement annoncée ;
- scénario ;
- prédiction.

## IA
Indiquer le rôle réel de l'IA : génération d'hypothèse, analyse, optimisation, rédaction, etc. Ne pas attribuer à "l'IA" un résultat qui relève principalement d'humains ou d'une expérimentation.

## Corrections
Une correction importante doit être visible et traçable, pas remplacée silencieusement.
