# Portefeuille des grandes questions

## Rôle des 10 questions initiales

Les 10 questions de lancement sont un **portefeuille de démarrage**, pas une liste définitive.

Elles ont été choisies pour couvrir :
- santé ;
- biologie ;
- robotique ;
- énergie ;
- IA scientifique ;
- informatique quantique ;
- espace.

## Critères d’admission d’une question

Une nouvelle question doit satisfaire au moins ces conditions :
1. intérêt humain immédiat ;
2. objectif formulable clairement ;
3. jalons observables ;
4. sources fiables et récurrentes ;
5. évolution mesurable dans le temps ;
6. absence de dépendance à un score purement subjectif.

## Critères de maintien

Une question peut être fusionnée, reformulée ou retirée si :
- ses jalons sont trop flous ;
- les événements significatifs sont trop rares ;
- elle duplique une autre question ;
- le public ne comprend pas l’objectif ;
- les sources ne permettent pas une vérification suffisante.

## Expansion

- lancement : 10 questions ;
- croissance : 30–50 ;
- maturité : 100–300+ si la méthodologie reste soutenable.

## Candidates futures

À évaluer, pas à ouvrir automatiquement :
- Alzheimer et neurodégénérescence ;
- régénération / organes ;
- interfaces cerveau-machine ;
- batteries / stockage ;
- nouveaux matériaux ;
- supraconductivité ;
- médicaments conçus par IA ;
- agriculture de précision ;
- capture carbone ;
- propulsion spatiale ;
- vie extraterrestre.

## Règle

**On n’ajoute pas une question pour remplir une catégorie. On l’ajoute parce qu’elle peut être suivie rigoureusement.**
