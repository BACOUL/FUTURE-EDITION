# Privacy-first

## V1
- pas de compte obligatoire ;
- pas de publicité comportementale nécessaire ;
- pas de fingerprinting ;
- pas de suivi intersite ;
- logs réduits au nécessaire.

## Analytics
Si une mesure d’audience est utilisée, privilégier une configuration strictement limitée à la mesure du site et compatible avec les exigences CNIL applicables.

## Données personnelles
Tout futur compte, alerte ou newsletter doit appliquer :
- minimisation ;
- finalité explicite ;
- durée de conservation ;
- export/suppression ;
- sécurité ;
- registre des traitements si requis.

## Ask Future Edition
Ne pas conserver par défaut plus de données conversationnelles que nécessaire au fonctionnement et à la sécurité.
