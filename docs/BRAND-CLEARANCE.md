# Brand clearance — Future Edition

## Statut
**PROVISIONAL NAME — NOT CLEARED**

Le nom Future Edition est conservé comme nom de travail et de construction.

## Usage public déjà identifié
En 2026, FIRST / FIRST LEGO League utilise officiellement l’appellation **Future Edition** pour une déclinaison de son programme éducatif. Cet usage ne tranche pas à lui seul la disponibilité pour un média, mais confirme qu’une clearance formelle est obligatoire.

Références de veille :
- https://firstlegoleague.org/
- https://www.firstinspires.org/programs/fll/

## Pourquoi il n’est pas encore gelé
Une recherche web ne suffit pas à établir la disponibilité juridique ou le risque de confusion.

## Gate avant identité définitive / lancement
Vérifier au minimum :
- marques françaises pertinentes (INPI) ;
- marques UE (EUIPO) ;
- marques internationales pertinentes ;
- noms commerciaux similaires dans médias, édition, logiciel/data ;
- domaines principaux ;
- principaux handles sociaux ;
- risque de confusion phonétique/visuelle.

## Décision
Le code et l’architecture avancent sous Future Edition. Aucune dépense de marque, dépôt définitif, campagne ou identité irréversible avant clearance documentée.
